Workshop/Ten prompts/04

Support different levels—keep the same learning goal

為中五經濟科設計不同程度的學習支援

Situation

An Economics teacher wants extra support and extension on the same concept, without giving different groups unrelated work.

Sources to add to Notebook

your approved demand-and-supply notes and diagrams, labelled “S5 Economics — Demand and Supply”; the relevant learning objectives.

Use one language version at a time. These are worked examples: adapt the source names to match your notebook.

English promptMarkdown / plain-text prompt

Use ‘S5 Economics — Demand and Supply’ to plan support for S5 HKDSE Economics. The shared goal is distinguishing a movement along a demand curve from a shift of that curve.

Use a three-column overview: Version; Support/challenge; Task idea. Plan A guided understanding, B application/analysis and C evaluation/creation. Fully draft A only, with plain-English vocabulary help, one worked step and two numbered items with answer spaces. Put explanations and citations in a separate Teacher key.

Preserve source definitions and diagram relationships. Treat versions as support, not ability labels.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請為HKDSE中五經濟科，用「S5 Economics — Demand and Supply」設計學習支援，共同目標是區分沿需求曲線的移動與需求曲線的移動。

用三欄概覽：版本；支援／挑戰；任務構思。規劃A引導理解、B應用分析、C評估創作。只完整編寫A版，包含淺白詞彙支援、一項示範步驟及兩道編號練習，留作答空位。另列教師答案、解釋及引用。

保留資料中的定義及圖像關係。版本是支援安排，不是能力標籤。

請以繁體中文回答。
Adapt this task: show the reusable templates

English promptMarkdown / plain-text prompt

Use the selected [topic] materials to plan support for [level] HKDSE [subject]. Keep this shared learning goal: [goal].

Use a three-column overview table: Version; Support/challenge; Task idea. Plan A guided understanding, B application/analysis and C evaluation/creation. Fully draft A only: short instructions, vocabulary help, one worked step and two numbered practice items with answer spaces. Put explanations and source citations in a separate Teacher key.

Treat versions as adjustable support, not ability labels. Label new tasks as teaching suggestions.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請為HKDSE[科目][年級]，用所選[課題]教材設計不同程度支援，共同目標是[目標]。

概覽用三欄表格：版本；支援／挑戰；任務構思。規劃A引導理解、B應用分析、C評估創作。只完整編寫A版：簡短指示、詞彙支援、一項示範步驟及兩道編號練習，留作答空位。另列教師答案、解釋及引用。

版本是可調整的支援，不是能力標籤；新任務標示為教學建議。

請以繁體中文回答。

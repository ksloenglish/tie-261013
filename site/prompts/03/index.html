Workshop/Ten prompts/03

Plan an HKDSE lesson with an exit ticket

規劃中四生物科滲透作用課堂

Situation

A Biology teacher needs a 40-minute lesson that moves from explanation to application and includes a quick understanding check.

Sources to add to Notebook

your approved osmosis notes and teacher-authored diagrams, labelled “S4 Biology — Osmosis”; relevant curriculum objectives. Add an applicable assessment framework if you want an examination-skills link.

Applicable HKEAA assessment frameworks ↗

Use the official documents applicable to your cohort. Add your own authorised teaching notes; they are not supplied by this website.

Use one language version at a time. These are worked examples: adapt the source names to match your notebook.

English promptMarkdown / plain-text prompt

Plan a 40-minute S4 HKDSE Biology lesson on osmosis using ‘S4 Biology — Osmosis’ and the selected curriculum objectives. This EMI class has varied prior knowledge, a projector and worksheets; no laboratory work.

Start with three key concepts and two learning goals. Use a four-column table: Minutes; Teacher actions/questions; Learner task/expected response; Check. Include a source-diagram demonstration, guided practice and independent application. Add three numbered exit-ticket questions and a separate answer key.

Cite biological explanations, label activities as suggestions and explain difficult terms simply.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請為HKDSE中四生物科，根據「S4 Biology — Osmosis」及所選課程目標設計一節40分鐘的滲透作用課堂。這是英語授課班，已有知識不同，有投影機及工作紙，不做實驗。

先列三個重點概念及兩項目標。用四欄表格：分鐘；教師行動／提問；學生任務／預期回應；檢查。包括資料圖像示範、引導練習及獨立應用，另列三道編號離堂小測題目及獨立答案。

引用生物學解釋，活動標示為建議，淺白解釋較難術語。

請以繁體中文回答。

English promptMarkdown / plain-text prompt

Plan a 40-minute lesson for [level] HKDSE [subject] on [topic], using the selected notes and objectives. Class context: [prior knowledge and available resources].

Start with three key concepts and two learning goals. Use a four-column lesson table: Minutes; Teacher actions/questions; Learner task/expected response; Check. Include a demonstration, guided practice and independent practice. Add three numbered exit-ticket questions and a separate answer key.

Cite subject explanations and label activities as teaching suggestions. Flag essential missing information.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請為HKDSE[科目][年級]，根據所選筆記及目標設計一節40分鐘的[課題]課堂。班別情況：[已有知識及可用資源]。

先列三個重點概念及兩項學習目標。教學流程用四欄表格：分鐘；教師行動／提問；學生任務／預期回應；檢查。包括示範、引導及獨立練習，另列三道編號離堂小測題目及獨立答案。

引用學科解釋，活動標示為教學建議，指出必要的資料缺口。

請以繁體中文回答。

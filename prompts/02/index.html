Workshop/Ten prompts/02

Turn an HKEAA briefing into revision-teaching notes

把歷史科簡報建議整理成溫習教學筆記

Situation

A History teacher wants to teach source interpretation explicitly instead of only assigning another set of practice questions.

Sources to add to Notebook

applicable HKEAA History teacher-briefing material if available; the applicable History assessment framework; authorised source-based-task guidance; and your own source-analysis task. The example explicitly handles a missing briefing without inventing its contents.

Applicable HKEAA assessment frameworks ↗

Use the official documents applicable to your cohort. Add your own authorised teaching notes; they are not supplied by this website.

Use one language version at a time. These are worked examples: adapt the source names to match your notebook.

English promptMarkdown / plain-text prompt

Use the selected HKEAA History briefing, assessment framework and source-based-task guidance to prepare S6 HKDSE History revision-teaching notes on source interpretation. State if no briefing is selected.

Use four headings: Key advice; Teaching explanations and practice; Possible difficulties; Checking question and answer. Give up to four cited advice points, each with a plain-language explanation and a five-minute practice idea using our source-analysis task. Add two possible difficulties and one checking question with an answer.

Separate reported candidate errors from teaching hypotheses; label new practice as suggestions.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請根據所選考評局歷史科簡報、評核大綱及史料題指引，為HKDSE中六歷史科整理史料解讀的溫習教學筆記。如未選取簡報，請說明。

用四個標題：重點建議；教學解釋及練習；可能困難；檢查問題及答案。列出最多四項有引用的建議，各附淺白解釋及以本校史料分析任務為基礎的五分鐘練習。再列兩項可能困難及一道檢查題與答案。

區分已報告的考生錯誤與教學假設，新練習標示為建議。

請以繁體中文回答。
Adapt this task: show the reusable templates

English promptMarkdown / plain-text prompt

Use the selected HKEAA briefing and assessment guidance to prepare revision-teaching notes for [level] HKDSE [subject] on [skill]. State if no briefing is selected.

Use four headings: Key advice; Teaching explanations and practice; Possible difficulties; Checking question and answer. Give up to four cited advice points, a short explanation and practice idea for each, two possible difficulties, and one checking question with an answer.

Label teaching suggestions separately. Only call an error a reported candidate pattern if the source says so.

Write in English.

繁體中文提示詞Markdown / plain-text prompt

請根據所選考評局簡報及評核指引，為HKDSE[科目][年級]整理[技能]的溫習教學筆記。如未選取簡報，請說明。

用四個標題：重點建議；教學解釋及練習；可能困難；檢查問題及答案。列出最多四項有引用的建議，各附淺白解釋及練習構思，再列兩項可能困難及一道檢查題與答案。

教學建議另作標示。只有資料明確指出的錯誤，才稱為已報告的考生表現。

請以繁體中文回答。
